# Eléctrica Dos Hermanos — sitio web (propuesta 2026)

Sitio de una sola página, sin dependencias: `index.html` + carpeta `img/`.

- **Ver local:** abre `index.html` en el navegador.
- **Fotos:** colócalas en `img/` con los nombres de `img/LEEME-FOTOS.txt`; las que falten se muestran como espacio marcado.
- **Configurar:** WhatsApp, horarios y coordenadas de cada sucursal están al inicio del `<script>` en `index.html` (bloque CONFIGURACIÓN).
- **Publicar:** GitHub Pages (Settings → Pages → rama `main`, carpeta raíz) o cualquier hosting estático.

Pendiente de confirmar con E2H: números de WhatsApp, horarios reales, ubicación exacta de Atlántico, años de apertura por sucursal, logo en vector.
